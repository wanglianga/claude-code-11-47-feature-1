# 防汛需求与道路情景覆盖数据分析平台

预案分析员在暴雨情景下比较居民在不同出发时刻，能否沿**可通行道路**到达**既有安置点**，
并区分覆盖面变化究竟来自**道路恢复、人口资料变化还是分析边界改变**。

平台只计算**可达人口及证据限制**，不做安置点选址、人员分配或物资调运。

本迭代新增**人口—路网连接证据治理**：每个网格份额都落在候选连接点证据上
（定位方法、误差范围、道路版本、人工确认记录），覆盖计算把**“路径可通”**与
**“人口确实有足够证据接入该路径”**分开，人口划入**确定可达 / 确定不可达 /
连接不确定**三类，连接不确定只按上、下界汇总，整格人口绝不重复计入多个安置点。

技术栈：**React 18 + TypeScript + Vite + Leaflet（离线 Simple CRS 平面地图）**、
**FastAPI**、**PostgreSQL 18**、**Redis 8（失效通知/任务状态，可选降级）**。

## 3. 数据与口径说明

### 3.1 来源目录（全部带原文、单位、发生/登记时间、修订号与证据截止点）

- 规则网格人口（含修订表与基准日）、路网节点、**有向边修订**、安置点及开放区间、
  封路/分时限速事件（**追加式多修订行** + 修订审计）、区域边界；
- **连接证据**：网格候选连接点（定位方法、误差范围、原始定位点、吸附距离、
  道路版本、道路等级、跨河标记）、空间阻隔（河流折线）、人工确认记录（追加式）；
- 事件每次修订只追加新行（含 `received_at`），快照按截止点取该事件最新的**可见**修订；
  因此旧截止点分析在新修订录入后仍可精确复现，不会被原地 UPDATE 改写历史。

### 3.2 情景工作区固定四项输入

人口基准日、出发时刻、允许行程时长、道路资料截止点（另可选分析边界）。
四要素 + 路网版本 + **连接证据版本** + 边界共同组成**完整情景签名**，作为缓存唯一键。

### 3.3 时变路网求解规则（`app/engine/traversal.py`）

1. 遍历边时检查**整条通行时段** `[进入, 离开)` 是否与封路区间相交，而非只看出发时刻；
2. 分时限速按覆盖整段的最严格限速计算（定点细化）；
3. 仅 `allow_wait` 节点可等待道路恢复，等待段与等待成本逐段记录；
4. 等待后到达仍超出总时限的标签被剪枝，**不计入覆盖**；
5. 安置点按**实际到达时刻**判断开放；到达时关闭且节点允许等待，可等到下一开放区间起点，
   等待同样计入总时长；
6. 每个标签携带见证路径（节点序列 + 边序列 + 等待段）。

### 3.4 人口—路网连接证据治理（本迭代新增）

**职责模块划分**（通过版本引用关联，互不内联）：

| 职责 | 模块 | 说明 |
| --- | --- | --- |
| 地址/空间证据接入 | `app/services/evidence.py` | 候选落库时计算跨河标记、道路等级（按道路版本出度：0=断头路/1=普通/≥2=主干）、吸附距离 |
| 连接审核与版本 | `app/services/connection.py` | 证据版本物化、人工审核批次、按版本解析有效连接状态 |
| 路径计算 | `app/engine/traversal.py` | 时变路网最短路（冻结，不读证据表） |
| 网格聚合 | `app/services/coverage.py` | 三分类、上下界、人口守恒 |
| 结果解释 | `app/routers/connections.py` + 前端「连接证据」页 | 候选、排除原因、上下界影响全程可查 |

**候选处置规则**（确定、可复算；人工审核结论优先于自动规则）：

1. 村级质心 **且** 跨越河流阻隔 → **自动排除**（低精度质心跨河不得默认接入最近道路）；
2. 村级质心、误差半径 > 200m、或跨河 之一 → **弱证据**（仅参与上下界）；
3. 其余（地址标准化/人工落点且误差可控且不跨河）→ **证据充分**；
4. 人工 `confirm` → 证据充分（可附权重覆盖）；人工 `reject` → 排除（留痕可查）。

**三分类与上下界**：

- **确定可达 / 确定不可达**：证据充分的候选按互斥份额切分人口，按路径可达性分类；
- **连接不确定**：弱证据或未配互斥权重的候选对应的人口**整块只计一次**；
  块内每个候选的路径评估留痕（`grid_candidate_results`），任一候选可达则该块计入
  **覆盖上界**，否则不计；绝不把整格人口重复加入多个安置点；
- **人口守恒恒等式**：总人口 = 确定可达 + 确定不可达 + 连接不确定 + 未知，
  每个任务落库时都满足（测试逐条断言）。

**版本纪律**：候选与审核均为追加式；人工确认在情景计算途中到达时只物化为
**后续连接版本**（`connection_versions`），情景签名引用版本号——已发布情景、
已完成任务与发布清单都固定在各自版本上，不会被改写；同参数新情景自动使用最新版本。

### 3.5 覆盖、去重与未知边界

- 份额人口 = 网格人口 × 互斥比例；同一份额能到多个安置点只计一次（取最早实际到达）；
- 网格级汇总天然去重，同一网格人口绝不重复计数；
- 未知单列且不默认全覆盖或零需求：
  `unknown_no_connector`（无候选）、`unknown_allocation_gap`（比例缺口）、
  `unknown_ratio_over_one`（比例矛盾）、`unknown_connector_missing`（连接节点不在该路网版本）、
  `unknown_no_plausible_candidate`（候选全部被排除）。

### 3.6 混合计算与缓存纪律

- 常规出发窗口**预计算**；临时封路/限速登记后立即参与后续**即时计算**；
- 每项结果标注**证据截止时间**；不同出发时刻/开放条件签名不同，缓存命中也不复用他者覆盖面；
- 封路修订沿 `task_edge_dependencies` 定位受影响任务，并显式筛查**恢复候选**
  （路网含该边但旧路径未经过的任务——重开可能恢复此前不可达区域）；
- 同截止点迟到修订物化为**新路网版本**（新指纹、新 version_id、新签名），
  旧任务物理上无法覆盖新版本缓存行；重建期间的路网更新只会再产生新版本。

### 3.7 对比报告的共同分母

- 仅在两侧共有的网格集合上计算覆盖率与变化；
- 道路/开放窗口效应、人口修订效应、分析边界增删、未知份额变化**分桶展示**，
  连接不确定人口变化单列（两侧连接证据版本不同时给出显式警告）；
- 人口或边界口径不一致时给出显式警告，不能把换了分母的覆盖率当作改善；
- 发布记录（`publications`）固化两侧完整输入清单（修订号、截止点、版本指纹、
  **连接证据版本**、网格人口与边界）。

## 4. 小型可手算样例（每条边 1000m / 60km/h = 1 分钟，T0=2026-07-15 08:00 UTC）

- 单向边 `E1(N1→N2)`（无反向边）、绕行 `N2→N5→N6→N4`；
- `EV1`：E3 河东桥 08:05–08:20 临时封闭，N3 不可等待；
- `EV2`：E1 分时限速 20km/h，08:10–08:30（该时段通过需 3 分钟）；
- `EV3`：E7 东站引道 C1 时“尚未恢复”，C2 修订为 08:40 重开；
- 安置点 S1@N3、S2@N6（07–18 点开放），S3@N7（仅 09–12 点开放）；
- 网格：G1 多点重叠、G2 双出口 0.6/0.4、G3 无连接、G4 比例缺口 0.3、
  G5 比例和 1.2、G6 人口修订 1000→1200、G7 属另一边界、G8 仅靠 E7 外接（恢复验证）。

### 手工复算要点

| 验证点 | 预期 |
| --- | --- |
| 08:05 出发去 N4 | E3 封闭且 N3 不可等待 → 绕行 E1,E4,E5,E6，08:09 到达 |
| 08:10 进入 E1 | 整段时限速 20km/h → 180 秒，08:13 到 N2 |
| G8（C1，任意时限） | E7 无恢复时间 → uncovered |
| G8（C2，30 分钟时限） | 最早 08:41 到 N7，等到 09:00 超过时限 → uncovered（等待后超时不计） |
| G8（C2，60 分钟时限） | 09:00 到达 S3，等待合计 3540 秒 → covered |
| G2 | 互斥份额 300/200，分别到 S1/S2，合计仍为 500，不翻倍 |
| G3/G4 缺口/G5 | 分别落入三类 unknown，未知人口单列 |

大区样例：8×8 规则路网（奇数行单向交通组织）、固定模式限速/封闭事件、
4 个角安置点、40 个网格（第 40 个无候选 → 未知）。

### 连接证据验收样例（GR 系列，清河 RIVER1 沿 y=-600 横贯）

| 样例 | 证据设计 | 验收结论 |
| --- | --- | --- |
| GR1 河岸村（650 人） | 低精度村级质心候选指向**直线距离最近**的 N1（跨河）→ 自动排除；地址标准化候选接同侧 N9（权重 1.0） | 不默认最近距离道路；确定可达 650（N9→E9→N2→S1） |
| GR2 南堰村（900 人） | 仅村级质心弱证据候选 →N10 | 整格连接不确定；人工确认后形成新连接版本转为确定可达，旧情景不被改写 |
| GR3 误标片（450 人） | 地址标准化误接到孤屯 N8（断头路，权重 1.0） | 确定不可达；人工纠正（接入 N3 + 排除误标 + 确认）后新版本确定可达，已发布清单仍固定旧版本 |
| GR4 双候选片（620 人） | 最近距离候选是断头路 N11，主干路候选在 N6，均未配互斥权重 | 整格连接不确定且只计一次；上界含 N6 可达性，下界不含 |
| GR5 东站引道片（750 人） | 弱证据候选接 N4 | C1 时 E7 未恢复 → 不确定且上界贡献 0；C2 重开 + 60 分钟 → 上界含 750（证据仍弱，不自动升级为确定） |

每个情景均满足：总人口 = 确定可达 + 确定不可达 + 连接不确定 + 未知。

## 5. 已执行的验证与结论

以下验证均在本工作区实际执行通过：

1. **后端单元/集成测试 41 项全部通过**（`pytest`，约 30 秒）：
   - 时变引擎：单向边、绕行、整段封路判断、分时限速整段生效、不可等待节点、
     等待后超时剪枝、安置点按实际到达时刻开放、见证路径留痕；
   - 基线覆盖：多出口互斥份额、多点重叠只计一次、四类未知边界、证据截止标注、边界过滤；
   - 缓存纪律：同签名复用与引用计数、不同出发时刻绝不共享缓存、临时事件即时失效、
     重开恢复此前不可达网格、旧任务不能覆盖新版本索引、旧截止点快照精确复现；
   - 对比发布：共同分母三因分解、人口修订不计入道路效应、边界变化单列、发布清单完整性；
   - **连接证据治理（8 项新测试）**：
     - 低精度质心跨河指向最近距离道路 → 自动排除，确定分类只走核实候选（GR1）；
     - 候选全部排除 → 整格 `unknown_no_plausible_candidate`，绝不回退到最近距离；
     - 断头路（最近）与主干路双候选未配权重 → 连接不确定，人口只计一次，上界含主干路可达性（GR4）；
     - 村级质心弱证据 → 不确定；人工确认只形成后续连接版本，旧情景结果不被改写（GR2）；
     - 人工纠正误标候选 → 新连接版本下确定可达，已发布清单仍固定旧版本（GR3）；
     - 多候选确认后确定可达恰增 620、不确定恰减 620，不重复计数（GR4）；
     - 道路修复（C2）后不确定网格上界重算：GR5 上界由 0 变为 750（GR5）；
     - 每个情景断言人口守恒：总人口 = 确定可达 + 确定不可达 + 连接不确定 + 未知；
     - HTTP 端到端：候选接入 → 审核批次 → 版本演进 → 网格概览 → 下钻候选评估。
2. **前端 `npm run build` 通过**（TypeScript 严格模式 + Vite 生产构建）。
3. **真实 HTTP 端到端验收通过**（uvicorn 实跑，7 步全过）：
   基线三分类与守恒（covered=38627、upper=40147、uncertain=2270、unknown=1983）→

## 6. 主要 API 一览

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/scenarios` | 按签名创建/复用情景并同步得到覆盖面（签名含连接证据版本） |
| GET | `/tasks/{id}/summary` `/grids` `/arrivals` `/witness` | 汇总（含上下界）、份额、节点到达、网格下钻（含候选评估与排除原因） |
| POST | `/tasks/{id}/release` | 查看者离开（引用计数，不取消他人任务） |
| POST | `/events` | 临时封路/限速登记并即时失效受影响范围 |
| POST | `/cache/precompute` `/cache/rebuild` `/cache/invalidate` | 预计算、重建、按边失效 |
| POST | `/comparisons` | 共同分母对比与三因分解（含连接不确定变化与版本差异警告） |
| POST | `/publications` GET `/publications` | 结果发布与完整输入清单（含连接证据版本） |
| GET | `/connections/version` `/connections/grids` `/connections/candidates` `/connections/barriers` | 证据版本、网格连接概览、候选明细、空间阻隔 |
| POST | `/connections/candidates` | 接入候选连接点（空间质检后物化新版本） |
| POST | `/connections/reviews` | 人工审核批次（confirm/reject/adjust_ratio → 后续连接版本） |
| GET | `/sources/*` | 来源原文、事件审计、边修订、安置点、人口与候选连接 |
| POST | `/admin/reseed` `/admin/apply-c2-revision` | 样例数据管理 |
